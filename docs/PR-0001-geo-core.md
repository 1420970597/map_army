## 变更概览

### 1. 测绘核心（src/core/geo）

- Krüger 六阶级数横轴墨卡托投影（含 Karney 2011 建议的高纬度发散处理）
- UTM 正反算与分带计算；MGRS 编解码（含 AA / MGRS-New 行字母奇偶带偏移）
- BNG（Airy 1830 椭球 + 七参数赫尔默特变换 + Bowring 迭代）
- 军网生成器：MGRS / UTM / BNG 三种网格按缩放层级自动细分

### 2. 军标符号引擎（src/core/symbology）

- 20 位数字型 SIDC 的解析、格式化、校验与构造（经三个独立来源交叉印证字段布局）
- 七种框架轮廓（矩形 / 菱形 / 正方形 / 四叶形 / 叶形 / 椭圆 / 半椭圆），
  形状 + 颜色 + 空实心三重冗余编码
- 地面 / 空中 / 海面 / 水下四大符号集核心实体图标；实体代码与第三方
  2525D 编码表逐条核对
- 梯队（圆点 / 竖条 / 叉号）、司令部 / 特遣队 / 佯动、状态、机动方向修饰符
- 昼间 / 夜间 / 单色三套配色主题

### 3. 数据模型与球面几何（src/core/model）

- 要素 / 图层 / 文档三级模型；Haversine 距离、方位角、球面过剩面积

### 4. 标图应用（src/features + src/stores）

- Leaflet 地图引擎：街道 / 地形 / 卫星三种底图，军网叠加层，要素图层
- 绘制交互：符号单击放置，线 / 面连续采点，双击或回车结束，Esc 放弃
- 符号选择面板（SIDC 组合 + 中英文搜索）、图层管理、属性检查器、
  坐标状态栏（经纬度 / MGRS / UTM 实时显示）
- 100 步撤销 / 重做；全局快捷键；本地自动保存

### 5. 导入导出（src/core/io）

- `.milxly`（JSON）与 `.milxlyz`（gzip）读写，宽容解析（损坏要素跳过并计数）
- GeoJSON 导入导出（SIDC 与文本修饰符写入 properties）
- PNG 图片导出；localStorage 防抖持久化

### 6. 静态站点与 PWA（site/ + public/）

- 内容文件 + 生成器产出五语言（zh/en/de/fr/it）× 三页面（关于 / 示例 / 文档）
  共 15 个本地化 HTML，含 hreflang 互链、canonical、JSON-LD 结构化数据
- 示例页符号由本项目军标引擎实时渲染，图文一致
- Service Worker：预缓存外壳与静态页、页面导航网络优先、瓦片缓存限量 500 条
- Web App Manifest（含 `.milxlyz` 文件关联）、可复现的 PWA 图标生成器、
  llms.txt / robots.txt / sitemap.xml
