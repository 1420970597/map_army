## 架构与数据归属

采用 FastAPI + SQLAlchemy + Alembic + MySQL 8.4；本地 S3 使用 MinIO。Python 负责鉴权、业务校验、事务、查询、迁移和后台任务。文件保存在 S3，文件元数据和引用关系写入 MySQL。渲染、鼠标手势、地图相机、临时量测及当前编辑撤销栈属于前端交互状态；已提交的数据及不可变版本以数据库为准。

工作空间使用独立访问凭证，数据库只保存凭证哈希；本轮不强制增加原站免费版没有的注册登录流程。访问凭证可以由用户保存并在另一设备连接同一工作空间。公开分享权限与私有工作空间权限相互独立。

格式工具是随 Python 后端部署的无状态兼容工具，不能读数据库或对外开放 HTTP。这样将文件处理迁往服务端，同时保留现有数百项格式回归的算法依据。客户端保留同一库作为明确的离线文件交换能力。该选择记录在 ADR，不能称为所有计算代码已改写成 Python。
