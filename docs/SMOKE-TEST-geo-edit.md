# 手动冒烟清单：几何编辑与选择模型（批次 1 `feature-geo-edit`）

> 用途：为 `docs/ARCH-geo-edit.md` §2.10「手动冒烟（6 步）」提供可执行的逐步说明。
> 适用范围：批次 1 落地的多选 / 框选、顶点增删改移与 N 点键位、顶点与绘制期吸附、
> 方向重置、复制粘贴、图层状态、跨图层移动、会话恢复与快捷键帮助。
> 前置环境：`npm install` 完成后执行 `npm run dev`，浏览器打开 `http://localhost:5173`。
> 每一步都写明**前置条件 / 操作 / 期望结果**；任一步期望结果不满足即为不通过，请记录实际现象。

---

## 第 1 步：绘制折线并验证「一次拖拽只产生一条撤销」

**前置条件**

- 应用刚打开或已清空文档（图层面板至少有一个未锁定、可见的图层，且它被设为活动图层）。
- 工具栏当前工具为**选择**（Select），地图为 2D 视图。

**操作**

1. 工具栏切换为**线（Line）**工具，在地图上依次点击 4 个点，按 `Space`（或双击）结束，
   得到一条 4 点折线。
2. 切回**选择**工具，单击该折线使其选中；此时折线上出现顶点手柄，要素本体被幽灵线取代。
3. 拖动第 2 个顶点到明显不同的位置后松开鼠标。
4. 按一次 `Ctrl+Z`。

**期望结果**

- 选中后：幽灵折线为蓝色描边（`--c-edit-accent`），4 个圆形手柄全部可见，拖拽中被拖的
  手柄为实心蓝底 + 橙色描边并放大。
- 拖动过程中地图不被整体平移；松开鼠标后几何一次性定型。
- `Ctrl+Z` **一次**即回到拖动前的形状（撤销栈只增加 1 条记录）；再按一次会退回到
  「绘制完成」之前的状态需要多次撤销，说明绘制本身的手势未被合并。
- 拖动后又 `Ctrl+Shift+Z` 可重做回拖动后的形状。

---

## 第 2 步：N 点键位——插入、删除与切换活动顶点

**前置条件**

- 承接第 1 步：一条 4 点折线处于**单选且已进入顶点编辑态**（手柄可见）。

**操作**

1. 按住 `Ctrl`（macOS 为 `Cmd`）在折线的某条**边**上点击（不是手柄上）。
2. 按住 `Shift` 点击刚插入的那个手柄。
3. 重新插入一个顶点，然后按 `Ctrl+→` 若干次、再按 `Ctrl+←` 若干次。

**期望结果**

- 第 1 步后折线变为 5 个点，新点落在点击位置最近的那条边上，且新点变为当前活动顶点
  （实心蓝底 + 橙色描边）。
- 第 2 步后折线回到 4 个点；当点数已到该几何的最小合法点数（线 2 点 / 面 3 点）时，
  `Shift+点击` 不再删除，几何保持合法，不出现渲染异常或控制台报错。
- 第 3 步中活动顶点按索引顺序循环移动，跨越首尾时不越界（末点按 `→` 回到首点）。
- 插入与删除各产生一条撤销记录，`Ctrl+Z` 可逐步回退。

---

## 第 3 步：吸附提示与 `S` 键开关

**前置条件**

- 地图上已有**两个及以上**要素（可先复制一份已有折线并移动开）。
- 状态栏的军网（MGRS / UTM / BNG 任一）已**开启并可见**。
- 选中其中一个要素进入顶点编辑态；吸附默认开启（`useEditStore.snapEnabled === true`）。

**操作**

1. 拖动一个顶点，缓慢靠近**另一个要素的某个顶点**（屏幕距离约 10px 内）。
2. 继续拖动该顶点靠近**军网网格线的交点**。
3. 在同一个顶点处于吸附命中状态时按 `S`，然后再拖一次。
4. 再按一次 `S` 恢复。

**期望结果**

- 步骤 1、2 命中时出现**橙色圆环吸附指示器**（半径 9px，白底半透明填充），圆心即吸附后的
  落点；松手后顶点停在候选点上，而不是鼠标原始位置。
- 未命中（距离超过阈值，约 10px）时不显示指示器，顶点跟随鼠标。
- 按 `S` 关闭后：拖动过程中**不再**出现指示器，顶点严格跟随鼠标；再按 `S` 恢复吸附。
- 快捷键帮助面板中 `S` 的描述为「切换吸附（绘制与顶点编辑均生效）」。
- 绘制一条新线时采点同样出现**同色同形**的吸附指示器，证明绘制期与顶点编辑共用视觉语义。

## 第 4 步：复制粘贴三次，偏移递增且属性完整

**前置条件**

- 地图上有一个带**自定义名称与非默认样式**的要素（便于核对属性是否完整保留）。
- 该要素已选中；活动图层未锁定。

**操作**

1. 按 `Ctrl+C`。
2. 连续按三次 `Ctrl+V`。
3. 分别选中三个副本，在检查器中核对名称、符号（SIDC）、样式与文本修饰符。

**期望结果**

- 每次粘贴都在当前活动图层新增一个副本，选择集切换为新粘贴的副本。
- 三个副本沿右下方**依次错开**，偏移量按粘贴次数递增（基准 24px，第 n 次为 24×n px），
  三者互不重叠，也不与原要素重叠。
- 副本的 id 与原要素不同；名称带 `副本` 或 `(n)` 后缀；SIDC、样式、文本修饰符、
  逐顶点方向（`vertexBearings`）均与原要素一致。
- 三次粘贴共产生 3 条撤销记录，`Ctrl+Z` 三次后全部撤销、文档回到复制前状态。

## 第 5 步：多选 + 框选追加 + 批量跨图层移动

**前置条件**

- 地图上至少有 6 个可点选要素，分布在能被一个矩形框住的区域。
- 图层面板中存在**另一个未锁定的目标图层**（例如名为「蓝方」）。

**操作**

1. 按住 `Ctrl`（macOS `Cmd`）依次点击 3 个要素。
2. 按住 `Ctrl` 在地图上拖拽出一个矩形，框住另外 2 个要素后松开（或先按 `B` 切到框选工具
   再拖拽）。
3. 查看右侧检查器顶部的批量提示。
4. 在检查器中选择「移动到图层 → 蓝方」。
5. 按一次 `Ctrl+Z`。

**期望结果**

- 步骤 1 后 3 个要素同时高亮；单选被替换、Ctrl 点击为增减切换。
- 步骤 2 后选择集**追加**为 5 个（原有 3 个 + 框选 2 个），不是替换；拖拽期间出现
  蓝色虚线矩形，地图不整体平移、不触发 BoxZoom。
- 拖拽位移小于 5px 时视为普通点击并清空选择，不会误选。
- 步骤 3 检查器显示「已选 5 个」之类的批量摘要，并提供批量操作按钮。
- 步骤 4 后 5 个要素全部归属目标图层，图层面板的要素计数与列表同步刷新；选择集保持不变。
- 步骤 5 **一次** `Ctrl+Z` 即把 5 个要素全部退回原图层（整批移动只产生 1 条历史）。

## 第 6 步：图层状态徽标、不透明度滑块与要素拖放

**前置条件**

- 图层面板可见，其中至少有两个图层。
- 至少有一个要素可用于拖放。

**操作**

1. 点击某个图层名左侧的**状态徽标**。
2. 拖动该图层的**不透明度滑块**从 1.0 到 0.3 后松开。
3. 按一次 `Ctrl+Z`。
4. 在图层面板中把一个**要素行**拖到另一个图层行上放下。

**期望结果**

- 步骤 1 徽标在「草稿 / 已核定」之间切换：草稿为浅灰蓝底深色字，已核定为浅绿底深绿字，
  两种状态在浅色面板中均清晰可读；切换立即持久化到会话。
- 步骤 2 拖动过程中要素不透明度实时变化，且在任意缩放下都不小于 0.05。
- 步骤 3 **一次** `Ctrl+Z` 即回到拖动前的整段不透明度（一次拖动只留 1 条历史），
  而不是回退一帧。
- 步骤 4 后该要素归属目标图层；拖放过程中源行半透明、目标行出现蓝色虚线轮廓。
- 若目标图层被锁定，则移动被拒绝，不产生撤销记录。

## 附加冒烟项（不占上述 6 步，建议同一轮顺带验证）

### A. 会话恢复确认

**前置条件**：在浏览器中正常编辑若干要素后，等待自动保存（状态栏出现「已自动保存」），
然后刷新页面。

**操作 / 期望结果**

- 刷新后顶部出现**全宽的浅蓝横幅**，文案形如「检测到上次会话（…前，N 个要素）」，
  右侧提供「恢复」与「丢弃」两个按钮。
- 点击「恢复」→ 横幅消失，要素回到刷新前的状态。
- 点击「丢弃」→ 横幅消失，本地会话被清空，回到空白文档。
- 另开一个标签页编辑同一份文档 → 原标签页出现**黄色冲突横幅**，提示当前编辑内容未被覆盖，
  点击「知道了」后横幅消失。
- 窄窗口（宽度 < 560px）下横幅文案自动折行，按钮组换行到第二行，不出现横向滚动条。

### B. 快捷键帮助面板

**前置条件**：页面焦点不在任何输入框内。

**操作 / 期望结果**

- 按 `?`（即 `Shift+/`）打开快捷键帮助面板；面板按「编辑 / 选择 / 视图 / 应用」分组，
  每行左侧为描述、右侧为键位徽标。
- 内容与 `src/core/shell/shortcuts.ts` 的 `SHORTCUTS` 注册表**逐条一致**
  （包括 `S` 的「切换吸附（绘制与顶点编辑均生效）」）。
- 按 `Esc` 或点击遮罩关闭面板。
- 在图层重命名输入框内输入 `s` / `z` / `x` 等字母时**不会**触发对应快捷键。

### C. 样式目视一致性

- 顶点手柄、幽灵图形、吸附指示器、框选矩形、图层状态徽标、会话横幅、快捷键帮助面板
  统一为**扁平浅色工程风格**：无嵌套卡片、无深色内嵌面板、无重复色值。
- 顶点编辑与绘制期的吸附指示器颜色与形状一致（同一套 CSS 规则）。
- 会话横幅为顶栏下方的通栏条，不呈现为浮层卡片。

## 受限项（环境限制，非代码缺陷）

| 项                                                          | 现象                                                                                                                                                                                                                                                                 | 说明                                                                                                                                                                                                               |
| ----------------------------------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |
| `npm run build`（= `npm run site && tsc -b && vite build`） | 前两步 `npm run site` 与 `tsc -b` 均通过；`vite build` 在准备输出目录、清空既有 `dist/` 时被 safe-delete 保护拦截并中断：`[vite:prepare-out-dir] [safe-delete][SAFE_DELETE_BULK_CONFIRM_REQUIRED] {"count":818,"threshold":50,"targets":["D:\map_army\dist\about"]}` | 属**环境限制**（待删除文件数 818 超过 50 的批量删除阈值），不是代码缺陷。**请勿绕过该保护**。替代验证：`npx tsc -b` 覆盖构建的类型检查环节，`npx vitest run` 覆盖回归；打包环节需先由人工确认清空 `dist/` 后再执行 |

> `dist/` 已被 `.gitignore` 忽略，构建产物不入库，故该限制不影响版本库内容与代码质量判定。
