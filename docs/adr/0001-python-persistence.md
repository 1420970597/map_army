# Python 管理持久数据，MySQL 管理关系，本地 S3 管理文件

用户要求将现有项目升级为 Python + MySQL + 本地 S3 后端。采用 FastAPI、SQLAlchemy、Alembic 与 MinIO；项目当前状态按项目/图层/要素分表，不可变修订保留完整交换数据。访问权限、引用校验和版本冲突在 Python 中执行，浏览器保留即时编辑、渲染和离线待同步副本。

现有 TypeScript 文件格式算法有大量回归与原站互操作证据。在线交换由 Python 调度受限的无状态格式进程，复用相同算法，避免全面重写 XML/AFSIM 解析造成字段丢失。Node 在此仅作为格式工具运行时，不再承载分享或任何持久化 HTTP 服务。原 Node 分享目录以只读迁移输入保留。

私有数据归属于独立工作空间，访问凭证只存哈希；分享继续沿用随机地址与独立编辑令牌。数据库提交前完成所需 S3 写入，失败不提交引用；未被引用的对象可通过清理流程回收。历史版本使用的资产不能随当前版本的删除而消失。
