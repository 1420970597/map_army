# 浏览器 Mover Creator 验收

范围：用户提供的 `/root/afsim/afsim_api_zip.zip` API 说明、本机 AFSIM 2.9 Mover Creator 源码与内置 AMC。完整支持其三维几何创作和本项目的挂载工作流；没有把气动求解、自动驾驶优化、飞行试验或任意 GLB 反求 AMC 参数标为已实现。

## 页面入口与操作

1. 打开 `http://localhost:8080`，点“工作空间 → 模型库 → 打开浏览器 Mover Creator”。内置列表可直接选择全部 34 个载具模板；45 个发动机和 12 份翼型数据在参数中选择。
2. 选模板或新建空白设计。组件树和场景选择同步；实例选择框可分别选镜像侧。修改 AMC 原始字段、新增/复制/删除组件、切换形状与对称、线框和显隐；固定组件不能改名或删除。
3. 增加挂点或安装锚点。可选择父组件并保留原世界位置；之后位置/角度/缩放为父组件局部坐标，拖动变换轴或输入数字均可修改。父组件移动或旋转时挂点跟随。
4. 勾选兼容部件的具体版本，再选择装配预览，或将已允许的部件拖入当前挂点的画布。一个部件 ID 在同一模型中绑定一个明确版本。可清空、替换、撤销、重做。
5. 保存生成不可变设计版本；可另存、恢复历史到新草稿、导出 AMC 与依赖 ZIP。下载 GLB 包含当前装配预览；发布保存基体及挂点/兼容目录，供军标详情独立装配。
6. 军标详情 → 三维模型 → 选择发布模型 → 拖入部件。支持撤销、刷新恢复、锁定/只读查看及“下载装配 GLB”。
7. 自定义 GLB 可导入编辑挂点，保留网格、纹理、透明材质与原文件；可调整整体位置/旋转/比例。AMC/ZIP 保留未知字段、发动机与 foil 原文。压缩几何/KTX2、外部纹理不是当前 GLB 导入格式；不可分解的剪切挂点报错，避免静默改变变换。

## 数据与实现边界

- MySQL `mover_designs/mover_versions`，Alembic `0002`；源 AMC/冻结依赖及生成 GLB 在本地 S3。历史引用由 AssetReference 保护，使用中的旧版本不被新发布覆盖。
- 本轮内置版本 `amc-6` 保留独立组件实例。开发验收产生的 `amc-1` 至 `amc-5` 仍保留，既有引用继续有效。
- 原生 C++ 几何内核不依赖 Qt/OpenGL；与 Python GLB 封装配合。Blender 继续负责自定义 OBJ 转换；没有声称 AMC 经由 Blender 反向建模。
- `.foil` 是性能曲线而非轮廓点。与原 Mover Creator 相同，翼面外形使用其七点对称轮廓。
- 备份恢复回归对比备份时的固定快照，避免同时浏览器写入导致误报；恢复仍仅写入新的随机测试数据库和桶，保护既有数据。
